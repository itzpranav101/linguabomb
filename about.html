How it works

The tutor does not rely on memory alone. It looks things up in open datasets first, then answers.

1You ask

You chat with a tutor persona and choose a language and level.

2Retrieve

The bot searches a small index of real phrases, words and sentence pairs (RAG).

3Answer

It teaches, quizzes or role-plays using the retrieved examples and says when it is unsure.

4Progress code

At the end it prints a code like LB-ES-B-7-LGPRQ. Paste it on the tutor page to earn XP.

The progress code

Behind the scenes your tutor reports a code after every activity and the site picks it up live, no copy-paste. You can still paste one manually under Advanced on the tutor page. The format is LB-<LANG>-<LEVEL>-<SCORE>-<DONE>. LANG is EN, HI, ES, FR, ZH or OT (other). LEVEL is B, I or A. SCORE is the latest quiz score from 0 to 8. DONE has one letter per finished activity: L learn phrases, G grammar, P practice round, R role-play, Q quiz, X extras. Syncing the same code twice never counts twice.

Safety comes first

1Stays on topic

The tutor only handles language learning. Off-topic or harmful requests are politely declined and redirected.

2Honest about being AI

Tutor personas are software. They never claim to be real people and never ask for personal details.

3Grounded answers

Examples come from open datasets. When the tutor is not sure, it says so instead of guessing. Romanisation for Hindi is rule-based, so treat it as a pronunciation aid.

Privacy note

This website has no accounts, no tracking and no server-side storage. Your XP, streaks, badges and synced sessions are saved in your own browser (localStorage) and never leave your device. Clearing your browser data, or pressing Reset data on the progress page, deletes them.

The AI tutor chat is provided by an embedded third-party widget that runs under its own privacy policy. Please do not share personal information in the chat. The fonts on this site are loaded from Google Fonts.
